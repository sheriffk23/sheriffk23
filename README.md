## 🚀 Featured Work

### 🔎 Project CORA — Code Repository Assistant

An AI assistant that helps developers understand unfamiliar repositories through natural-language questions and explanations grounded in code references.

**Focus:** Semantic search, retrieval-augmented generation and developer learning.

**Stack:** Python · OpenAI · RAG

### 🔁 RelayGuard — Reliable Webhook Delivery

A backend service that persists events, retries temporary delivery failures and exposes delivery history through an authenticated dashboard.

**Focus:** Idempotency, exponential backoff, worker crash recovery and failed-event replay.

**Stack:** Python · FastAPI · SQLite · HTTPX · Docker · pytest

### 📅 Annual Leave Management System

An internal application developed during my placement at CompuCal, supporting leave workflows, user administration and calendar functionality.

**Focus:** Business workflows, REST APIs and JWT authentication.

**Stack:** React · .NET · SQL Server · Kendo UI
